## Integration contract

- **Control-plane:** existing QPueblo master evidence ledger / index registry / QIFY-QRX workbook; this page does not declare which historical artifact is canonical.
- **Data-plane:** event/claim rows must carry source URL, publication/observation dates, evidence grade, jurisdiction, entity aliases, issue and child-impact tags, source TTL, correction history, and record version.
- **Twin-plane:** simulations cannot be represented as observed facts. Public aggregated indicators only.
- **Audit-plane:** write receipts and raw evidence belong in the controlled archive, never auto-synchronized into this public repository.
- **Activation:** all signal, alert and twin import processing is disabled pending explicit human authorization. Git commits here do not imply QPueblo website publication.

## Memory coherence / amendment rule

Use packet ID plus a monotonically increasing version to link each new source, correction or contested interpretation to its predecessor. Never replace source excerpts without an amendment event. No claims of automated ChatGPT long-term memory updates are made by this index.
