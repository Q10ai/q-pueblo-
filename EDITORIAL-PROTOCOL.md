# Q-Pueblo Editorial and Correction Protocol — Public Beta

## Publication boundaries

- Independent, nonpartisan regional governance and public-finance research.
- Distinguish SOURCE, EVIDENCE, ASSERTION, ISSUE, ENTITY, RELATIONSHIP, EVENT, MONEY_INSTRUMENT, PLACE_POPULATION and OUTCOME.
- Treat public comments as SIGNAL, not automatically as evidence. Organized volume does not establish independent corroboration or consensus.
- An issue research queue is not a misconduct finding and does not prove a current project status.
- State the effective/as-of date, geography, source publisher, legal authority, version, uncertainty, and TTL for every consequential factual assertion.
- Proposed cost, authorized cost, contracted amount, invoice, cash disbursement, clawback and realized benefit are separate financial states.
- An institutional link is not evidence of improper conduct.
- Never silently overwrite historical snapshots; append amendments with who, when, why and controlling source.
- Provide fair source-backed competing explanations, but do not inflate unsupported claims as equal evidence.
- Simulations are conditional models, not forecasts or policy endorsements.
- Preserve human consent, review, override, shutdown and rollback.
- Protected private data, sensitive allegations, minors, credentials and confidential submissions must not enter public GitHub issues or the public repository.

## First-release limits

The repository contains a client-side source directory and research navigation. It does not import unreviewed Q10 ledger assertions, run autonomous AI agents, accept private intake, or claim a real-time source feed. A named human editorial process and independent privacy/security review are prerequisites to enabling those capabilities.

## Correction sequence

Receive specific claim -> redact/quarantine unsafe input -> identify controlling source and version -> verify jurisdiction/time -> compare independent evidence -> record counterevidence -> human disposition -> append supersession note -> publish dated, reversible amendment.
