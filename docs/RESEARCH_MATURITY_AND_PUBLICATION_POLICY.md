# Q-Pueblo: two independent release axes — 2026-11-08
Status: CANDIDATE / REVIEW REQUIRED. This document refines earlier NO-GO wording; it does not bypass security, privacy, law or human authorization.

## A. Website platform readiness (global)
Production may occur after the app's identity, security, accessibility, deployment credentials, review permissions, monitoring, backup/restore, rollback, critical bug fixes and actual hosted behavior are verified. These are platform-wide checks. A private/unreviewed source corpus must never be public, regardless of how complete a website appears.

## B. Subject and packet maturity (per record)
The website may be live while most individual issue, entity and source packets are incomplete. A publicly safe topic heading with an evidence-gap explanation can be listed before a detailed QIFY packet exists. Incomplete substantive claims must never be presented as verified findings.

Stages:
1. DISCOVERED — initial signal, not yet checked. Visibility: internal by default; safe neutral public metadata only after screening.
2. INDEXED — public-safe navigation identity and scope, not a finding.
3. RESEARCHING — dated sources, open questions, affected entities are being gathered; private evidence remains controlled.
4. EVIDENCE_DEVELOPING — atomic claims, alternative explanations, counterevidence, finances, and metadata checked individually; unreviewed or contested allegations remain on hold.
5. REVIEWED_FINDINGS — specific human-reviewed claims may be published only with source, time, privacy/rights/Child Core review, and explicit approval. This status does not imply a full packet.
6. COMPREHENSIVE_PACKET — full QIFY analysis, citations, conflicts, rights, 5W1H, money, historical states, micro-to-macro, TSLP, scenarios and a Child Impact Statement across past/present/future.
7. MONITORING — revision, TTL and source-change review of the current approved derivative; monitoring is not claimed until actually configured.
8. SUPERSEDED_ARCHIVED — old record preserved with version link, effective date and correction rationale; sensitive deletions require retention/legal/privacy review.

**Maturity is NOT the publication decision.** Every object must also have `publication_state` (NAVIGATION_ONLY, REVIEW_REQUIRED, APPROVED_PUBLIC, PRIVATE_HOLD, REJECTED), `evidence_state`, `security_class`, `source_lineage`, `event_at`/`recorded_at`/`expires_at` when applicable, `human_owner`, privacy/child gate, and a `supersedes_id` or amendment events. Publishing a nav label does not approve claims attached to its private packet.

## Public listing rule
For `NAVIGATION_ONLY`, release *only* a neutral preexisting public subject title, nonaccusatory scope and a 'not verified' note. No sensitive person-level profile, child/private location, inference of wrongdoing, exposed draft evidence, unsourced causal story, fabricated status or false completion claim. This public index is built from the original already-public Q-Pueblo issue/institution navigation, never automatically from private Q10 control packets or held assertions.

## Public full-packet rule
A detailed finding requires source identity and dates, source rights, human editorial approval, open-counterclaim treatment, recorded uncertainty, rights/safety screen, past/present/future Child Impact Statement, issue-specific risk assessment and retraction/repair path. If any are material and unresolved, hold *that claim or field*, not the neutral site navigation or other independently verified records.

## Learning and multiple-perspective rule
A user may read historical stages, compare several properly attributed interpretations and explore hypothetical alternatives. Each view is versioned independently; no perspective counts as a new independent original source simply because it was quoted or reposted. Fictional lens labels and simulated future outputs are persistent at every level. Learners can inspect incomplete packets to practice evidence literacy, without exposure to private details or unreviewed allegations.

## Import and promotion
Each historical candidate from the 2025–2026 archive enters protected intake → identity/alias deduplication → publication-sensitivity screening → safe neutral index if allowed → claim-level verification → human-controlled public derivative. The imported count and coverage must be reported honestly; importing 102 historical issue rows, for example, does not create 102 verified public packets. All updates append source/version receipts. No autonomous publishing.
