# Q-Pueblo visual release candidate

Owner direction: use the supplied logo and website design reference, dark blues
and purples, highlights matching the logo, images and icons, desktop and mobile.

The supplied 1000024932.png is used without creative alteration as
public/assets/q-pueblo-header-wide.png. The original square logo remains.
brand-theme.css loads after individual styles on all twenty HTML pages.

Eleven original illustrated topic images were generated with the built-in image
tool, using 1000024931.png as style reference. Prompts covered Colorado civic
architecture, budgets, community, infrastructure, small business, environment,
education, industrial heritage, resilience, housing, and AI/transparency; no text,
seals, logos, numbers, charts or documentary claims. Web exports are bounded to
800px and lazy-loaded. The page labels artwork illustrative.

Phosphor Icons Core 2.1.1 supplies locally bundled SVGs under MIT; the license is
shipped next to the icons. No public icon CDN, external font service or analytics
is introduced. Unsupported live/automation claims in the visual reference remain
excluded; dated records and human publication review are authoritative.

Design QA and release receipts describe checks. A source commit is not deployment.
