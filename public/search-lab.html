Search with evidence in mind.

Use publicly available search operators to find primary records. A search result is a lead, not a verified finding. This page composes query text locally; it does not run searches or transmit what you type.

Operator reality check

Documented basics

Quotes, site:, filetype:, exclusions and Google's before:/after:. Bing also documents inbody:.

Unreliable or retired

Google's cache: is retired. intitle:, inurl:, source: and other advanced examples are not guaranteed across engines.

What proves a claim?

Original bytes, authoring authority, date, independent corroboration, contradictions and review receipts—not a search ranking.

Q Pueblo verification path

Question → Search plan → Original record → Dates and authority → Counterevidence → QIFIED analysis → Human review → Versioned report.
