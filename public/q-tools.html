02 / T2Y

Test Truth-to-Yield

Reference instrument

Score each factor 0–1. T2Y does not substitute for evidence checks; results are provisional and must never authorize release. Values are user estimates.

T2Y = truth × realized yield × agency × reversibility × (1 − harm); reference thresholds: truth ≥ 0.80, harm ≤ 0.20, T2Y ≥ 0.35. All gates conjunctive; no score creates public-release authority.
